# Chromatic Dusk Palette

Working name: **Chromatic Dusk**. This replaces the old **Jemo** naming direction with a more colorful, saturated palette for the editor and terminal theme.

## Core surfaces

| Role | Preview | Hex | OKLCH | Use |
| :--- | :--- | :--- | :--- | :--- |
| Night plum | █ | **#111231** | `oklch(18% 0.055 285)` | Main editor background |
| Deep iris | █ | **#1A1C40** | `oklch(23% 0.060 282)` | Sidebar, panels, inactive tabs |
| Violet well | █ | **#282946** | `oklch(29% 0.052 292)` | Current line, selections, raised surfaces |
| Dust mauve | █ | **#55464B** | `oklch(43% 0.030 12)` | Muted text, guides, disabled UI |
